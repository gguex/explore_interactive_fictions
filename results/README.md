# Generated results

Result artifacts are organized first by pipeline phase, then by book. Within a book,
the optional subdirectories distinguish their role:

```text
results/
├── phase1/LW01/
│   ├── curnagl/       # raw cluster returns and prompt-calibration history
│   └── presentation/  # figures and descriptive statistics for slides
├── phase4/LW01/
│   └── presentation/  # graph and Bag-of-Paths presentation artifacts
└── phase5/LW01/
    ├── curnagl/       # raw trajectory-annotation runs returned by the cluster
    ├── calibration/   # prompt-comparison reports
    └── presentation/  # final trajectory-analysis figures and tables
```

Canonical machine-readable pipeline data remain under `data/processed/`; `results/`
contains remote-run records, calibration reports, and presentation-ready derivatives.
Most generating scripts also accept an explicit output path when a different layout is
needed.

There are no separate `phase2/` or `phase3/` result directories: their canonical
pregraph and compiled Markov-chain outputs live under `data/processed/pregraph/` and
`data/processed/graph/`. The neutral graph image is a phase-4 presentation artifact,
because it is generated by the phase-4 visualization script.
